# Mapa kontakata

Veb aplikacija za iPhone: učitate kontakte izvezene iz aplikacije Kontakti (.vcf) i vidite na mapi gde ko živi.

- Kontakti se čuvaju samo na telefonu (u pregledaču). U ovom repozitorijumu nema ličnih podataka.
- Adrese se pronalaze preko OpenStreetMap Nominatim servisa (najviše jedan upit u sekundi). Šalje se samo adresa, bez imena i telefona.
- Mapa: © OpenStreetMap saradnici, © CARTO.

Otvorite https://jombebrat.github.io/mapa-kontakata/ u Safariju, pa Podeli → Dodaj na početni ekran.
